# Jellyfin_fpl — Нативный Jellyfin-плеер с браузером папок и офлайн-загрузками (XGB35 Linux)

Нативный порт на базе пользовательского форка Streamyfin (`upstream/`, скопирован из `D:\grav\streamyfin_my`) для приставки **XGB35 / ATM7051H** (`ARMv7 Cortex-A5 NEON`, Alpine Linux `musl`), очищенный от лишних витрин, рекомендаций, Seerr, Live TV, Chromecast, SyncPlay и тач-жестов:

- **Два режима экрана**:
  - **Linux Desktop (HDMI / X11)**: изменяемое окно и полный экран `F11` (`MIT-SHM`), поддержка USB-мыши (клики, колесо прокрутки, клик по полосе прогресса) и физической клавиатуры.
  - **Портативный экран `480×320` (`/dev/fb0`)**: прямой вывод `RGB565` `1:1` с автоопределением поворота `ST7796S`, чётким векторным рендером кириллицы/латиницы (`FreeType` + `DejaVuSans`) и встроенной экранной клавиатурой (`RU` / `EN` + быстрые вставки `http://`, `192.168.`, `:8096`).
- **Все 4 ключевых модуля из `streamyfin_my`**:
  1. **Авторизация и сессия**: вход по URL + логину/паролю, вход по **Quick Connect** (6-значный код на экране), авторизация другого устройства по коду в настройках, атомарное сохранение сессии в `data/config.json`.
  2. **Браузер по папкам (`HomeFolders` + `FolderBrowser`)**: карточка «Папка последнего просмотра», список папочных библиотек, постраничная навигация (`50` элементов), рекурсивный поиск по папкам с русской нормализацией (`ё` -> `е`), превью-миниатюры, статус просмотра (`Просмотрено` / `Остановка на ...` / длительность).
  3. **Единый видео + аудио плеер без тач-наворотов (`FFmpeg` + `ALSA S32_LE`)**: Direct Play и серверный транскодинг Jellyfin с выбором битрейта (`Max`, `20M`, `8M`, `4M`, `2M (480p)`, `1M`, `420k`), выбор аудиодорожки и субтитров (`SRT`/`WebVTT`/встроенные), сохранение позиции и отчёт на сервер, автопереход к следующему файлу папки.
  4. **Офлайн-загрузки (`OfflineDownloadsBrowser`)**: скачивание отдельных файлов и «Скачать папку целиком», вкладки `Очередь (N)` (пауза/возобновление/отмена) и `Скачанное` с деревом папок (`folderTree`), локальными обложками и `.vtt`-субтитрами для полностью автономной работы без сети.

## Управление
- **Крестовина / Левый стик / Стрелки** — навигация по спискам и кнопкам плеера (в плеере без фокуса кнопок `Вверх`/`Вниз` — перемотка `±10с`, `L1`/`R1` — `±30с`).
- **`A` / `Enter` / ЛКМ** — открыть папку, запустить файл, нажать кнопку.
- **`B` / `Esc` / ПКМ** — назад в родительскую папку / закрыть плеер или меню.
- **`X` / `Del`** — скачать выбранный файл (во вкладке «Папки») или отменить/удалить загрузку (во вкладке «Загрузки»).
- **`Y`** — быстрый переход к поиску по папкам.
- **`L1` / `R1` / `Tab`** — переключение вкладок `Папки` / `Загрузки` / `Настройки`.
- **`START` / `Space`** — Пауза / Воспроизведение в плеере; **`SELECT`** — включение курсора стиком; **`SELECT + START`** — быстрый выход; **`F11`** — полный экран X11.

## Сборка и установка
```powershell
python ports/Jellyfin_fpl/build_port.py
python ports/Jellyfin_fpl/deploy_adb.py --selftest
python ports/Jellyfin_fpl/deploy_adb.py
```
