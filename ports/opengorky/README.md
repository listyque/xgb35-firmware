# OpenGorky (Gorky 17 / «Горький-18») — Порт для XGB35 (ATM7051H Linux)

Нативный порт движка **OpenGorky** (точная реимплементация *Gorky 17 / «Горький-18»*) для приставки **XGB35** (**Actions ATM7051H**, dual-core `armv7` Cortex-A5 + NEON/VFPv4, 212 МБ RAM, Alpine Linux `musl`) без зависимости от SDL2/SDL3.

## Оптимизации под XGB35 (опыт StarDroid)
- **ATM7051H Display Engine (`DE_ML0 @ 0xB02F0000`)**: в полноэкранном HDMI-режиме (X11 Desktop) игра выводит `640×480` RGB565 напрямую в `/dev/fb1`, а аппаратный скейлер `DE_ML0` масштабирует кадр в `1440×1080` / `960×720` за **0,0 мс CPU**.
- **Портативный экран 3,5″ (`480×320`, `/dev/fb0`)**: кэшируемый `16×16` поворот под ST7796S, NEON-даунскейл `640×480 → 480×320` и переключение **`L2` / `F2`** между полным экраном и чётким режимом **`1:1 (480×320)`** со слежением за курсором.
- **Экономия памяти и производительность (212 МБ RAM, dual-core Cortex-A5)**:
  - Внутренний кадровый буфер и `frame_tex` в `RGB565` (600 КБ) с zero-copy обменом указателей (`frame_tex ↔ backbuf ↔ Core 1 /dev/fb0`).
  - Автоматическое сжатие статических фонов и спрайтов в `RGB565` / `ARGB1555` (**−50% RAM**).
  - 3D-слой актёров в `320×240` с маской теней `256×256` и быстрым 2× блиттером на `640×480` + кэширование 3D-слоя между тиками мира (`30 Hz`), оба ядра Cortex-A5 (`S.pool.init(2)`), `scaling_governor=performance`.
  - Предустановленный `opengorky.cfg`: `hires = 0`, `upscale = off`, `launcher = 0`. В режиме `--play` порт пропускает сканирование 140 архивов и показывает анимацию `pila.spr` во время загрузки.
- **Видеоролики (`.asf`) и звук**: встроенный декодер **FFmpeg 6.1.1** (`libavformat`/`libavcodec`/`libswscale`/`libswresample`/`libavutil` из `/mnt/sd/ports/Jellyfin_fpl/lib`) + прямой вывод `ALSA S32_LE` (HDMI `pcmC1D0p` или динамик `pcmC0D0p` + `tinymix 35 1`).

## Рендерер в Desktop Mode

Ярлык OpenGorky открывает выбор режима. Enter запускает Software (CPU). Кнопка PowerVR SGX540 (Direct) включает прямой вывод через WSEGL. У обоих режимов общие настройки и сохранения. Портативный ярлык использует программный режим.

SGX растеризует небольшие пакеты геометрии с текстурами и строит маску теней. Полная порция из 256 треугольников или сумма ограничивающих прямоугольников больше половины кадра переключает пакет на программный растеризатор. Для теней драйвер читает только занятую область в RGB565. Анимация костей, проверка глубины и интерфейс выполняются на CPU. При отказе EGL используется программный растеризатор.

Аппаратные пакеты группируются по материалам. В игровом рендерере у треугольников остаются прежние позиции в буфере растеризации, поэтому глубина и прозрачность собираются в исходном порядке. В отдельном стенде на SGX540 при Z24 группировка 467 непрозрачных треугольников сократила число вызовов GL со 209 до 12. Медиана прохода без чтения пикселей уменьшилась с 7,54 до 2,84 мс, контрольные изображения совпали пиксель в пиксель.

Внутри Alpine Desktop режим можно выбрать и из командной строки.

```sh
cd /mnt/sd/ports/opengorky
./OpenGorky-Desktop.sh --software
./OpenGorky-Desktop.sh --sgx
./OpenGorky-Desktop.sh --sgx-direct
```

`--sgx-direct` включает экспериментальный рендер спрайтов через GLES2 и прямой вывод в HDMI framebuffer. Нужен WSEGL из `xgb35-firmware/drivers/sgx540/wsegl-fbdev.c` с поддержкой поверхности 640×480 для аппаратного скейлера. Обновлённый WSEGL выделяет общую память для потоковых текстур, в которую игра записывает изменённые участки. Запуск приостанавливает Xorg на время игры, поэтому его нужно делать из оболочки с правом отправлять сигналы Xorg. Игровые скриншоты в этом режиме недоступны. 3D-персонажи и их тени пока рисуются на CPU.

На XGB35 в бою `01__port_citadel` исправленный режим SGX показал 26,6 FPS при 640×480. Прежний SGX показал 9,9 FPS, программный режим — 25,5 FPS. В бою новый режим рисовал модели на CPU, маску из 1044 треугольников — на SGX.

Для сборки из другой копии движка нужны две точки подключения в `src/render`. Копия в `upstream/` уже их содержит. [Патч движка](src/scene-renderer.patch) · [Драйвер Alpine](../../multiboot/README.ru.md#драйвер-для-alpine-desktop)

## Управление

В Desktop-ярлыке режим **SGX Debug** включает модели и тени на SGX, асинхронный вывод и запись времени кадра в `/tmp/opengorky_last.log`. Для этого режима сборщик берёт WSEGL с поддержкой `OG_SGX_ASYNC` из `sgx-inspection` и упаковывает его в каталог игры. В бою удерживайте SELECT и нажмите указанную кнопку или используйте USB-клавиатуру. Повторное нажатие возвращает проход. Цифры после минуса у счётчика FPS показывают отключённые проходы.

В SGX Debug цвет персонажей сохраняет разрешение сцены 640×480. Отдельный проход пишет аппаратную глубину с шагом 2×2. Глубина фона использует ту же сетку, маска теней остаётся 512×512. В лог попадают размеры буферов для занятого прямоугольника кадра.

| Клавиша | С SELECT | Что отключается |
|---|---|---|
| F5 | A | Весь слой персонажей и теней, включая подготовку на CPU |
| F6 | B | Проекция, маска и наложение теней |
| F7 | X | Цветной фон и спрайты объектов уровня. Глубина фона сохраняется |
| F8 | Y | Отрисовка слоя после подготовки моделей и проекции теней на CPU |
| F9 | R1 | Упаковка и передача глубины фона в режиме с моделями на SGX. Z-тест между моделями сохраняется |

- **Левый стик / USB-мышь** — курсор (`L1` замедляет для точного наведения).
- **Правый стик / Крестовина** — прокрутка камеры (`WASD` / стрелки).
- **`A` / ЛКМ** — действие / выбор; **`B` / ПКМ** — отмена / режим прицеливания в бою.
- **`X`** — `Space` (следующая реплика / скрыть панель); **`Y`** — `I` (инвентарь).
- **`L1`** — замедление курсора / `Q` (след. оружие); **`R1`** — `E` (конец хода).
- **`L2` / `F2`** — переключение `640×480` ↔ `1:1 Zoom (480×320)` на LCD.
- **`R2`** — `Tab` (сетка боя); **`SELECT`** — `F` (камера на героя); **`START`** — `Esc` (меню); **`SELECT + START`** — выход.
- **`F11`** — полноэкранный режим в X11 Desktop (включает `DE_ML0`).
