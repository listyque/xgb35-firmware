# Статус прошивок и мультибута

[EN](firmware.md) · **RU**

| Проект | Статус |
| --- | --- |
| [Восстановленная штатная прошивка](../firmware/stock/README.ru.md) | Пакет PATO со сборкой от августа 2023 года проверен на ПК. Установка этим пакетом на приставке ещё не проверялась |
| CFW для XGB35 | Linux запускался из RAM с ADB через WinUSB и терминалом на экране. Отдельная сборка CFW в разработке |
| [Предварительный установщик мультибута XGB35](../multiboot/README.ru.md) | Готовит microSD из локальных образов загрузки, Alpine и штатной системы. Загрузочный образ содержит разрабатываемую CFW для XGB35 и предоставляется пользователем. Холодный старт с карты ещё предстоит проверить |
| [SuperX CFW от Powkiddy](superx-port.ru.md) | V1.1 поддерживает X39, X39 Pro, X45, X51 и X70. План порта для XGB35 составлен по релизу SuperX и локальным файлам |

В следующих релизах нужно указывать ревизию платы, носитель загрузки, хеш файла и результаты проверок на приставке.
