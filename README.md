# XGB35 (ATM7051H) · Stock Firmware, CFW и мультибут

![Портативная игровая консоль XGB35 с экраном 3,5 дюйма](https://imgaz3.staticbg.com/thumb/large/oaupload/banggood/images/7E/63/02f22f34-783a-42d9-942a-22dad2963375.jpg)

**XGB35** — портативная игровая консоль на Actions Semiconductor **ATM7051H**. Здесь описан экземпляр с платой **LLW7051-057-MAIN-BOARD V2.0** от **2022‑07‑19**, LCD со шлейфом **XXL03518B** и внутренней NAND Micron на **8 ГиБ**. Название XGB35 встречается у нескольких продавцов. При сравнении прошивок сверяйте маркировку платы и панели.

**English summary:** XGB35 retro handheld hardware documentation and board photos, reconstructed stock firmware, custom firmware (CFW), microSD multiboot, and the status of the SuperX CFW port from Powkiddy devices.

## SuperX CFW от Powkiddy

**SuperX CFW** — сторонняя прошивка проекта `scooper540/powkiddy-X39-X45-X51-X70-cfw`. Релиз **V1.1** заявлен для **Powkiddy X39, X39 Pro, X45, X51 и X70**. Для XGB35 порт ещё не подтверждён. Сборки для XGB35 будут публиковаться отдельно после проверки дисплея, управления, загрузки и восстановления. [Репозиторий SuperX CFW](https://github.com/scooper540/powkiddy-X39-X45-X51-X70-cfw) · [Релиз V1.1](https://github.com/scooper540/powkiddy-X39-X45-X51-X70-cfw/releases/tag/V1.1)
