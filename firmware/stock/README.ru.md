# Штатная прошивка XGB35 · 22 августа 2023 года

[EN](README.md) · **RU**

- **Скачать:** [`update.zip` в релизе GitHub](https://github.com/listyque/xgb35-firmware/releases/download/stock-2023-08-22/update.zip)
- **Размер:** 72 764 416 байт
- **SHA-256:** `957ab55ae5c8af8994f47b4b403d64808c59b2bb01cc9af7f443302c761516e2`

Этот пакет **Actions PATO OTA** восстановлен из старых компонентов прошивки, считанных с NAND проверенного XGB35. Версия контейнера `2.0.00.230822.0628` составлена по дате и времени исходной сборки. Оригинальный заголовок OTA 2023 года не сохранился. Все компоненты пакета взяты из старого бэкапа NAND.

| Запись PATO | Содержимое |
| --- | --- |
| U-Boot | Старый загрузчик, извлечённый из NAND. Обновлятор записывает его в загрузочную область |
| MISC | Старое ядро, дерево устройств, ramdisk и параметры загрузки |
| RECOVERY | Старый раздел восстановления со штатным обновлятором |
| SYSTEM | Старая ОС в SquashFS со штатной программой `manager` |
| RES | Старые ресурсы интерфейса в SquashFS |

На ПК проверены сигнатура PATO, границы записей, контрольные суммы заголовка и компонентов, обе CRC U-Boot и файловые системы. **Восстановленный OTA-пакет ещё не устанавливали на приставку.** Пакет обновляет загрузочную область, а старый MISC выбирает профиль **1024×600**. Его совместимость с проверенной панелью 320×480 ещё предстоит подтвердить. Разделы CONFIG, UPGRADE и пользовательский GAME находятся за пределами пакета.
