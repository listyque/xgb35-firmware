Вернуть XGB35 к жизни

Этот комплект для Windows 10/11 x64 восстанавливает загрузочный блок приставки через USB. ADFU — режим восстановления, который может работать даже с чёрным экраном.

Сначала сверь приставку

На плате должно быть написано LLW7051-057-MAIN-BOARD V2.0, рядом дата 2022-07-19. На микросхеме NAND — Micron 29F64G08CBABA WP:B. Если надписи отличаются или их не видно, остановись до записи.

1. Распакуй и открой комплект

Щёлкни по скачанному ZIP правой кнопкой, выбери Извлечь всё и открой получившуюся папку. Установки Python не требуется, он уже внутри.

Щёлкни по START.cmd правой кнопкой, выбери Запуск от имени администратора и подтверди запрос Windows. В меню введи 1 и нажми Enter для установки драйвера.

2. Подключи приставку

Выключи её, вынь карту microSD, подключи USB-кабель с передачей данных. Один раз нажми Reset. В меню введи 2. Сообщение «Windows видит ADFU» означает, что можно идти дальше, даже если экран чёрный.

Если ADFU не появился, сверь кабель и USB-порт. На указанной ревизии есть два маленьких круглых контакта прямо у надписи ADFU слева от NAND. Если уверенно нашёл оба, соедини их на время Reset и убери перемычку, когда Windows обнаружит устройство. Снова введи 2.

3. Сохрани копию и запиши образ

Введи 3. Меню попросит подтвердить маркировку. Программа сначала сохранит в папке backups копию двух загрузочных блоков, затем проверит связь и снимет ещё одну копию блока 0. На это может уйти несколько минут.

Когда программа попросит ввести ВОССТАНОВИТЬ, это последнее подтверждение. После него она сотрёт и перезапишет физический блок 0, затем проверит результат. Во время записи не нажимай Reset и не отключай USB или питание. Нажми Reset, когда появится сообщение «Проверка завершилась».

Если что-то пошло не так

Если программа остановилась с ошибкой, сфотографируй окно. Сохрани папку backups и журнал из tools\nand-write-preparation. Если ошибка возникла после подтверждения записи, часть блока могла уже измениться. Для этого случая в технической инструкции описаны проверка текущего блока и возобновление.

Копия инструкции лежит в tools\TECHNICAL.ru.md. Её можно открыть в Блокноте. Техническая инструкция на GitHub
