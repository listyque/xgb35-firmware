# Установщик мультибута XGB35 · предварительная версия

[EN](README.md) · **RU**

[Релиз установщика](https://github.com/listyque/xgb35-firmware/releases/tag/multiboot-installer-v0.1.0)

Утилита для Windows готовит **отдельную microSD** для XGB35 из локальных файлов сборки. Она помещает загрузочный образ Actions BootROM перед первым разделом и устанавливает на этот раздел файловую систему Alpine и образы штатной системы для 480×320. Среду выполнения и графическое меню предоставляет локальная загрузочная сборка XGB35.

## Требования

- Windows, Python 3.11 или новее и установленный WinUSB-драйвер для ADB-устройства XGB35 `10d6:fe02`.
- Работающая загрузка XGB35 из RAM с ADB и `/bin/xgbshell`.
- Запасная microSD в приставке. Установка заменяет MBR и форматирует карту.
- Локальные файлы сборки XGB35 по схеме ниже. Архив установщика содержит утилиты для ПК. Загрузочный образ с CFW XGB35, Alpine и образы штатной системы берутся из локальной сборки.

```text
build-artifacts/
  sd-boot-autonomous/
    manifest.json
    sd-boot-lba1.bin
  alpine-bundle/
    manifest.json
    alpine-xgb35-rootfs.tar.gz
  update.zip_DATA/
    3.system.img
    5.res.img
```

Для SYSTEM и RES нужны **образы штатной системы для 480×320**, которые использует среда XGB35. В штатном пакете восстановления от августа 2023 года другой профиль экрана. Установщик сверяет ожидаемые SHA-256 обоих файлов до подключения к приставке.

## Проверка и установка

В папке с распакованным установщиком проверьте входные файлы без обращения к USB:

```powershell
python install_sd.py --inputs 'D:\path\to\build-artifacts'
```

Когда XGB35 загрузится из RAM и вы вставите запасную карту, запустите установку с явным указанием на стирание карты:

```powershell
python install_sd.py --inputs 'D:\path\to\build-artifacts' --erase-sd
```

Установщик проверяет, что Linux определяет `/dev/mmcblk0` как SD-карту, записывает загрузочные секторы и монтирует новый раздел 1, начинающийся с LBA 32768. Затем он устанавливает `/linux/alpine.ext4`, `/linux/stock-system.img` и `/linux/stock-res.img`, сверяет загрузочную область и штатные образы обратным чтением и размонтирует раздел. Целевое устройство установщика — microSD.

**Статус проверки.** Валидация входных файлов и самотест протокола ADB прошли в Windows. Установку и самостоятельный холодный старт ещё предстоит проверить на приставке. Отдельная CFW дорабатывается.
